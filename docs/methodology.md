# 模型解释、结果复核与边界

## 数据与时间

官方发布包中的C题PDF、附件1—4和五个结果模板与本次输入逐字节一致。购电模板从00:10—00:20起算，与储能模板00:00—24:00存在10分钟差异。本方案把每个输入时点解释为此前10分钟平均功率，输出对应自然日区间；只修正结果副本时段标签，原文件未修改。`time_mapping.csv`给出144个标签的逐项对照，`input_manifest.json`给出输入校验值。

原始数据365天无缺失日期；光伏中的微小夜间正值保留，不擅自清零。附件3的预报目标为发布时间加1—24小时，不按固定列号映射到当天同一小时。最后一天跨年预报仍可作为决策输入，但没有对应2026年实测的目标不参加误差评分。

附件1近似等于全年对应曲线的均值，但它是赛题事先提供的资料。模型可使用这个给定先验；不能因此自行计算附件2或4全年统计量用来制定过去的策略。

## 预测与选模

问题二正式主模型单独采用联合因果预测：前一日、前一周和最近7日中位数构成三个基预测，最近14日以净负荷绝对误差估计负载、光伏非负组合权重；最近30日残差的逐段分位数与小时池化分位数各占一半。5倍紧急购电价格在无储能单区间近似下对应80%临界分位数，故80%在全年评价前固定；70%和90%仅用于敏感性回放。

固定价问题的负载和光伏预测不读取附件4。为验证隔离性，测试把整个附件4价格矩阵改变后，三种预测方法的固定价预测必须保持完全相同。

朴素预测组合过去同星期曲线、最近7天曲线与附件1先验；岭回归和梯度提升学习该基准的残差。超参数在评价前固定，训练仅使用过去最多60天已经揭晓的样本。连续未来48小时预测从当前起点直接生成，第二天的预测不能取尚未出现的第一天实际曲线。

历史情景由同一历史起点产生的完整预测与已揭晓实际量的差构成。最多使用过去60天的合格残差块，按时间均匀选择12块、等权评价；保持负载、光伏、价格同一历史片段的配对关系。功率为加性误差，价格为对数误差。单情景对照严格为零残差点预测。

一月候选实验各自从1月1日6000 kWh出发，1月15日的库存不必相同。比较1月15—31日费用时，同时保存期初、期末库存，并以附件1最低电价除以0.9作统一库存估值。这个校正是比较指标，不是额外电费。正式一月运行固定朴素策略，不按月底模型选择重写已经发生的动作。

所有四项选模均选择naive。问题3中boost的库存校正费略低，但改善约0.161%，低于预先规定的0.5%选择阈值。不能据此宣称复杂模型在其他月份必然较差，也不能看到全年费用后再改变模型选择规则。

## 参考优化与实际控制

问题二正式主模型的48小时线性规划只生成计划购电，前24小时提交、后24小时提供跨日库存价值；日内不调用4小时MPC。当前10分钟有余电时在功率与容量约束内尽量充电，有缺口时先放电，剩余缺口才紧急购电。该反馈与修改稿口径一致，是唯一正式执行路径。

以下12情境与4小时MPC说明适用于问题三、四以及问题二的 `scenario_reference` 对照，不适用于问题二正式采用的风险裕度—即时反馈模型。

所有未来计划购电、充放电和SOC轨迹在情景间共享；情景内可变化的是紧急购电和未利用余电。模型没有给每条情景独立、提前知晓未来的储能轨迹。48小时参考规划的终点6000 kWh、4小时MPC的参考终点均属于有限时域规划的设计参数，不是对每个真实日末强制恢复6000的要求。

MPC参考终点会先投影到从实际库存出发、在当前控制窗口内可达到的容量区间。这在2小时敏感性实验中尤其必要；实际执行经过安全层限制后仍可能偏离参考终点，下一步用实际库存重新规划。

当前区间的实测平均量只能用于实时安全跟踪的离散近似和事后结算，不用于重算该区间起点的优化。充电不得超过满足负载后的计划与光伏余量；放电不得超过原目标和当期缺口；紧急购电只补剩余负载缺口。必须区别“参考优化允许估计未来缺口成本”和“实际紧急电可以主动充电”两种说法，后者在本方案被禁止。

线性规划同充同放净化证明只证明参考优化存在互斥的同费用解。安全层和滚动反馈构成受限的可执行控制策略，不由该证明自动获得全年最优性。最终所有电量和费用来自实际回放。

## 调整结算

原计划为q0，最终有效承诺为q，主费用为p*q0-0.5*p*max(q0-q,0)+1.5*p*max(q-q0,0)+5*p*u。该恒等式表示：保留电量按原价支付，取消量只支付0.5倍违约费用，新增量按1.5倍支付。6、12、18时中间承诺不分别累加计费；可以撤销先前的调整，最终账单只对午夜原计划结算一次。

自然结算下，下调1 kWh相对保留原计划可节省0.5p，因此参考优化必须同时允许上调和下调。无储能单时段中，原计划低于需求的70%分位数时倾向上调，高于90%分位数时倾向下调，位于两者之间时维持原计划。“原计划全额另加0.5倍下调违约费”的保守解释仅作敏感性对照；在正电价和免费处置条件下，它才具有不下调的支配性。

## 评价解释

总费用、紧急电量、弃余电、储能吞吐、期初期末储电量分别报告。紧急电量下降不自动意味着总费用下降。本题固定价全更新策略的总费用略增，必须保留这一实际结果。

按日配对自助区间是对该年度时序样本差异的描述，采用7天循环区块与2000次重采样；它不替代跨年份验证，不把边际费用差异夸大为稳定优越性。

完全信息下界使用全年365天真实净负载和价格，允许自由年末库存并免除紧急及调整附加费用。它是放宽约束后的理论下界，不能称为可执行策略或与334天费用直接相减。只知道未来价格的对照仍包含净负载预测误差与控制近似，费用可能不单调下降，不能将单次负改善误解为信息本身没有价值。

## 人工核验

程序测试、逐时守恒校验、模板单元格核对及编译检查均属于自动检验。最终对假设的接受、公式理解、关键数值复算、文字采纳和AI参与披露仍需参赛队按实际情况完成。不得把自动检验报告替换为未发生的人工审查记录。
